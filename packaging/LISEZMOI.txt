FRANÇAIS
--------

Aucune installation n'est nécessaire : décompressez l'archive, puis lancez
Manifestival. Manifestival n'est pas signé numériquement : au premier
lancement, le système demande une confirmation.

Windows
  Double-cliquez sur Manifestival.exe. Si Windows affiche « Windows a protégé
  votre ordinateur », cliquez sur « Informations complémentaires », puis
  « Exécuter quand même ».

macOS
  Déplacez Manifestival.app dans le dossier Applications si vous le
  souhaitez. Au premier lancement, faites un clic droit (ou Ctrl+clic) sur
  Manifestival.app, choisissez « Ouvrir », puis confirmez « Ouvrir ». Si
  macOS refuse, ouvrez Réglages Système > Confidentialité et sécurité, et
  cliquez sur « Ouvrir quand même » en bas de la page.

Linux
  Lancez Manifestival dans le dossier décompressé (double-clic, ou
  ./Manifestival dans un terminal).

Mode d'emploi : menu Aide > Mode d'emploi.
Signaler un problème, nouvelles versions :
  https://github.com/MarjorieBurghart/Manifestival


ENGLISH
-------

No installation is needed: unzip the archive, then start Manifestival.
Manifestival is not digitally signed: the first time, your system asks you
to confirm.

Windows
  Double-click Manifestival.exe. If Windows says "Windows protected your PC",
  click "More info", then "Run anyway".

macOS
  Move Manifestival.app to the Applications folder if you wish. The first
  time, right-click (or Ctrl-click) Manifestival.app, choose "Open", then
  confirm "Open". If macOS refuses, open System Settings > Privacy &
  Security, and click "Open Anyway" at the bottom of the page.

Linux
  Start Manifestival in the unzipped folder (double-click, or
  ./Manifestival in a terminal).

How to use: Help menu > How to use.
Report a problem, new versions:
  https://github.com/MarjorieBurghart/Manifestival
